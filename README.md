# Dent Up — сайт стоматологии в Чиланзаре

Одностраничный сайт на двух языках: русский на `/`, узбекский (латиница) на `/uz/`. Статичная сборка без
зависимостей: нужен только Node.js 18+. Готовый сайт — папка `dist/`, её можно положить на любой хостинг.

## Запуск

```bash
node scripts/build.mjs
```

```bash
node scripts/serve.mjs
```

Сайт откроется на http://localhost:4183. Проверить тему вручную: `http://localhost:4183/?theme=day` или `?theme=night`.

## Идея дизайна

Клиника принимает круглосуточно, поэтому главный элемент — циферблат суток на первом экране. Полукруг от 00:00 до
24:00 похож на путь солнца по небу, а текущее время Ташкента идёт по нему абрикосовой точкой. У сайта две темы:
дневная (светлая) и ночная (тёмная). С 20:00 до 06:00 по Ташкенту он открывается в ночной теме, днём — в дневной.
Посетитель может переключить тему кнопкой в шапке: новая тема раскрывается кругом от кнопки.

Шрифты: Unbounded (заголовки, цифры), Golos Text (текст). Цвета и размеры — в начале `src/styles/site.css`.

| Разметка разделов | `src/render/page.mjs`, циферблат — `src/render/dial.mjs` |
| Часы, тема, сборщик сообщения, меню, карта | `src/scripts/site.js` |
| Значок, картинки для соцсетей, настройки хостинга | `public/` |

После правок снова запустите `node scripts/build.mjs`.

**Цены.** На сайте цен нет: клиника их не публикует, а 2ГИС и соцсети их не дают. Когда появится прайс, его можно
добавить в `services` в словарях (поле с ценой «от») и вывести в плитках услуг.

**Фото врача.** Сейчас вместо фото — инициалы в круге с делениями. Положите квадратный снимок (от 800×800, лучше
оригинал с телефона) в `public/img/doctor.webp` и укажите `photo: "img/doctor.webp"` в `src/content/business.mjs`.
Для страницы `/uz/` путь станет `../img/doctor.webp` — проще указать абсолютный `/img/doctor.webp`.

**Картинки для соцсетей.** После изменения заголовка: `node scripts/og.mjs`, затем `node scripts/build.mjs`.
Скрипт снимает шаблоны через Chrome (нужен установленный Chrome или Edge) скриптом `page_shots.mjs` из skill студии.

## Заявки

Формы с сервером нет. Кнопки «Позвонить», «Telegram» и «WhatsApp» открывают звонок или мессенджер:

- **Telegram** — личный чат врача `@toshkent_stomatolog_sirojiddin` с готовым текстом. Посетителю остаётся нажать
  «Отправить», сообщение приходит врачу от самого пациента.
- **WhatsApp** — номер `+998 88 878 87 88` с тем же текстом. Номер в WhatsApp не проверен (см. ниже).
- Сборщик сообщения в разделе «Записаться можно на любой час» подставляет в текст выбранное время и повод.

Сайт ничего не хранит и не отправляет сам. Аналитики и счётчиков нет. Ссылки помечены `data-track`, чтобы при
желании владельца подключить счётчик звонков и переходов.

## Публикация

1. Соберите с адресом сайта, чтобы появились canonical, hreflang, картинки для соцсетей и sitemap:

   ```bash
   SITE_URL=https://ваш-домен.uz node scripts/build.mjs
   ```

   В PowerShell: `$env:SITE_URL="https://ваш-домен.uz"; node scripts/build.mjs`

   Без `SITE_URL` сборка — черновик: страницы закрыты от поисковиков (`noindex`), `robots.txt` запрещает обход.
   Черновик по живому адресу: добавьте `NOINDEX=1` вместе с `SITE_URL`.
2. Загрузите **содержимое** папки `dist/` (не саму папку) в корень сайта. `.htaccess` для Apache/LiteSpeed уже
   внутри: своя страница 404, https, кэш.
3. Проверьте: главная и `/uz/` отвечают 200, несуществующий адрес — 404 со своей страницей, картинка
   `https://домен/og/og-ru.png` открывается.
4. Поставьте ссылку на сайт в карточке 2ГИС и в профилях Instagram и Telegram.

Домен и хостинг регистрируются на клинику.

## Что проверить у клиники

- **Часы.** Название профиля, 2ГИС и Telegram говорят «24/7, по записи», но в посте от 19.04.2026 был график
  8:00–2:00. Сайт пишет «круглосуточно, по предварительной записи».
- **WhatsApp.** В 2ГИС у клиники WhatsApp нет; кнопка ведёт на +998 88 878 87 88. Проверить, что номер есть в WhatsApp.
- **PhD и 8 лет практики** — со слов врача в его Instagram. Хорошо бы увидеть диплом.
- **Бесплатная консультация** — только из 2ГИС.
- **Помощь на дому** — по одному посту; уточнить, делает ли клиника это постоянно.
- **Написание имени врача** кириллицей не подтверждено, поэтому на обеих версиях имя латиницей, как в его профиле.
- **Узбекский текст** написан не носителем — нужна вычитка.
- **Лицензия** на медицинскую деятельность: номер на сайте не указан, его стоит добавить в подвал.
- **Instagram в 2ГИС** ведёт на недоступный @dentupclinic; актуальный — @dentup_kids.
- В Instagram врача есть упоминание «сонной методики» для детей. На сайт не вынесено, пока не ясно, что это
  (медицинская седация требует отдельных формулировок).
